Place your team profile photos in this folder.

File naming convention:
  ganesh.jpg   → for Ganesh
  raghu.jpg    → for Raghu
  arjit.jpg    → for Arjit Ujjawal

Then update TeamCredits.jsx — set the `image` field for each person:

  image: '/team/ganesh.jpg'
  image: '/team/raghu.jpg'
  image: '/team/arjit.jpg'

Supported formats: .jpg, .jpeg, .png, .webp
Recommended size: at least 300x300 px (square)
If the image fails to load, the emoji avatar is shown as fallback.
